## Clasification Metrics
### Accuracy
Ration of correctly predicted instances to the total number of instances

### Confusion Matrix
Breaks down ground truth instances of a class against the number of predicted class instances

### Precision
Mesures how many predicted positive instances are actually positive
- how many true positive and false positive
true positive/(true positive + false positive)

### Recall
Messures how many actual positive instances are correctly predicted
- how many true positive and true negative
true positive /(true positive + false negative)

### F1 score
Combines precision and recall to prepresent a model's accuracy.
Used when precision and recall are equaly important.
Represents a harmonic mean of precision and recall.
(2 * precision * recall)/(precision + recall)

## heuristics

cluster assisted learning (refining clusetr using other machine learning methods)

## metrics
### Silhuette score:
compares cohesion within each cluster
accesses separation from other clusters
range -1 to 1
higher values indicate better diffined cluser

### Davies-Bouldin Index:
Mesures cluser compactness ratio
Asseses separation from the nearest cluster
Lower values indicate more distinct clusers
Indicate more compact clusers

### Inertia:
Usied in k-means clustering
Calculates the sum of variances within clusers
Lower values suggest more compact clusters
Increasing the number of clusers reduces variance creating a tradeoff
